# Triage labels

The skills speak in terms of five triage roles. This file maps those roles to the label strings in this repo's issue
tracker.

| Label in mattpocock/skills | Label in our tracker | Meaning                                    |
| -------------------------- | -------------------- | ------------------------------------------ |
| `needs-triage`             | `needs-triage`       | Maintainer needs to evaluate this issue    |
| `needs-info`               | `needs-info`         | Waiting on reporter for more information   |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an agent alone  |
| `ready-for-human`          | `ready-for-human`    | Requires human implementation              |
| `wontfix`                  | `wontfix`            | Will not be actioned                       |

When a skill mentions a role (such as "apply the AFK-ready triage label", AFK meaning an agent working alone), use the
label string from this table.
